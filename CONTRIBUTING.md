# Contributing to HyperStrata

HyperStrata is a personal experiment where I cook: my targets, my rig, including throwaway runs that cost time/money before anything ships.

Pull requests are not accepted right now — single 8 GB rig, and I implement what covers many users myself so every number stays honest and measured here.

What IS welcome from users (people who run it): bug reports with rig + server log, bench reports with logs per `docs/COMMUNITY_BENCHMARKS.md`, hardware notes.

Fake numbers get the report closed. No timeline promised.
