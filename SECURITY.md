# Security

| Version | Supported |
| --- | --- |
| 1.x (latest) | Yes |
| < 1.0 | No |

## Report

Report privately via the repository Security tab, Report a vulnerability ([direct link](https://github.com/theacidblack/HyperStrata/security/advisories/new)).

## Include

What you found, how to reproduce (request, config keys, version), what an attacker gains.

## Response

Owner triage. No backports. No promised timeline.
